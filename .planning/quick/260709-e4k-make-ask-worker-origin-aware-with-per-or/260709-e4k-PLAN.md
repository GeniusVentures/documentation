<objective>
Make the ask Cloudflare Worker origin-aware so that multiple documentation sites (e.g., `docs.gnus.ai` and `gcs.gnus.ai`) sharing a single worker deployment each get their own per-origin caches. The worker resolves a relative `LLMS_URL` (`/llms.txt`) against the validated request Origin at runtime instead of hardcoding a single domain.
</objective>
