## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-13 | Information Disclosure | API keys in CI logs | mitigate | Environment variables are not printed by build.sh (existing pattern with set -euo pipefail); build-graph.py logs provider name only, never key value (per Plan 01 T-08-04); GitHub Actions masks secret values by default |
| T-08-14 | Elevation of Privilege | CI job executing build-graph.py with API keys | mitigate | build-graph.py only reads documents and writes llms-meta.json — no network access beyond LLM API endpoints; script is versioned in the gendoc-template repo alongside the workflow definition; per D-09, only parent project admins can configure the API key secrets |
| T-08-15 | Denial of Service | Build time increase from LLM calls | accept | LLM calls per-document add latency to build; mitigated by incremental reanalysis (LLMGRAPH-08 — unchanged docs skip LLM calls); graph step is skippable by omitting API keys; worst case first-build time is acceptable |
</threat_model>
